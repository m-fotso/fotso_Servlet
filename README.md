🍽️ Restaurant Discovery Web App
A full‑stack project built to explore API integration, backend engineering, and interactive UI design.

✨ What This Project Is
This application is a restaurant discovery tool that lets users search for places to eat, explore results on an interactive map, and save their favorites. It was built as part of my Principles of Software Development course, but I approached it like a real product: clean architecture, modular code, and a focus on user experience.

The project combines backend engineering in Java with a dynamic front‑end and real‑world APIs — a great example of how I approach full‑stack development.

🎯 Key Highlights
Integrated the Yelp Fusion API to power restaurant search by name, coordinates, and filters like rating, distance, and review count

Built backend services in Java using Servlets and GSON to handle requests and parse JSON

Implemented secure user authentication (login/signup) with JDBC and SQL, including persistent favorites

Designed a responsive UI with HTML5, CSS3, and JavaScript

Used XMLHttpRequest to fetch data asynchronously and update the interface

Added Google Maps integration to visualize nearby restaurants and navigation

Deployed the full application on Apache Tomcat 9.0

🧩 How It Works
The user logs in, searches for restaurants, and gets results pulled directly from Yelp’s API. The backend processes the request, formats the data, and sends it back to the front‑end, where JavaScript renders the results and updates the map. Users can save favorites, which are stored in a SQL database and tied to their account.

It’s a simple experience on the surface, backed by a full stack of technologies working together.

🛠️ Tech I Used
Backend: Java, Servlets, GSON, JDBC, SQL, Tomcat
Frontend: HTML5, CSS3, JavaScript
APIs: Yelp Fusion API, Google Maps JavaScript API
